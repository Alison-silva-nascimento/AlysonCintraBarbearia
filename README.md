# Alyson Cintra Barbearia

Site institucional da **Alyson Cintra Barbearia**, desenvolvido com uma identidade Black & White premium e referências de barbearia clássica americana.

[Ver site publicado](https://alison-silva-nascimento.github.io/AlysonCintraBarbearia/)

## Sobre o projeto

A página apresenta os serviços, barbeiros, duas unidades, galeria de ambientes, rotas de localização e canais de contato da barbearia. A experiência foi pensada para desktop e mobile, preservando navegação simples, contraste elevado e acesso direto ao agendamento pelo WhatsApp.

## Destaques

- Layout responsivo para desktop, tablet e mobile.
- Hero com fotografia, faixa animada e transições suaves.
- Cards de serviços com imagens coloridas e ampliação ao toque.
- Perfis dos barbeiros Alyson Cintra e Lucas Santos.
- Galeria de ambientes com visualizador de imagens.
- Unidades, Google Maps e Waze.
- Navegação móvel com atalhos, abas e barra de ações.
- Formulário local para perguntas e feedbacks.
- Respeito à preferência de redução de movimento do dispositivo.

## Tecnologias

- HTML5
- CSS3
- JavaScript puro
- GitHub Pages

## Estrutura

```text
.
├── assets/              # Logos, fotos e demais recursos visuais
├── css/
│   ├── global.css       # Variáveis, reset e estilos globais
│   ├── components.css   # Componentes reutilizáveis
│   ├── home.css         # Estrutura das seções da página
│   └── american-classic.css # Direção visual e ajustes responsivos
├── js/
│   └── main.js          # Navegação, abas, diálogos e interações
└── index.html
```

## Executar localmente

Como é um site estático, basta abrir o arquivo `index.html` em um navegador. Para uma experiência mais próxima da publicação, sirva a pasta por um servidor local:

```bash
python -m http.server 8080
```

Depois, acesse `http://localhost:8080`.
